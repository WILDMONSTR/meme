# Meme Studio

GitHub Pages에서 바로 실행할 수 있는 정적 밈 이미지 편집기입니다.

## 기능
- 동일한 기본 캐릭터를 유지하면서 표정 교체
- 기본 감정 SVG 스티커와 밈 문구 제공
- PNG / JPEG / WEBP / SVG 업로드
- 요소 이동 / 확대·축소 / 회전 / 투명도 / 색상 / 레이어 / 복제 / 삭제
- 텍스트는 캔버스에서 더블클릭하여 수정
- 1:1 / 4:5 / 9:16 화면비 선택
- 화면비 변경 시 현재 이미지·문구 배치를 유지하면서 세로 공간을 재배치
- PNG 저장
- 서버/빌드/패키지 설치 불필요

## GitHub Pages
1. 저장소 생성
2. 이 폴더의 파일을 저장소 루트에 업로드
3. Settings → Pages → Deploy from a branch → `main` / `/ (root)` 선택
4. 게시된 주소 접속

외부 JavaScript CDN에 의존하지 않도록 만들어 인터넷에서 라이브러리를 불러오지 못하는 환경에서도 기본 편집기가 표시됩니다.
### 이미지 색상 처리
기본으로 제공되는 SVG 스티커와 사용자가 업로드한 이미지는 원본 색상을 그대로 유지합니다. 오른쪽의 색상 도구를 사용했을 때만 색상 효과가 적용됩니다. PNG 저장 결과도 편집 화면과 동일하게 출력됩니다.


### 기본 문구 스타일
기본 문구는 짧은 인터넷 말투 중심으로 제공되며, 캔버스에 추가될 때 글자색·두꺼운 외곽선·약간의 회전이 프리셋마다 다르게 적용됩니다.
