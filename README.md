# Meme Studio — SNS 밈 짤 편집기

브라우저에서 동작하는 정적 밈 이미지 편집기입니다. 서버나 데이터베이스가 필요하지 않으며 GitHub Pages로 바로 배포할 수 있습니다.

## 주요 기능

- 동일한 고정 포즈의 캐릭터 + 표정 교체
- 문구 추가/수정/색상/크기/위치/회전
- 감정 이모지 추가/수정/색상/크기/위치/회전
- PNG / JPEG / WebP / SVG 사용자 이미지 업로드
- 업로드 이미지 이동/확대·축소/회전/투명도 조절/복제/삭제
- 레이어 순서 변경
- 배경색 변경
- SNS용 1080×1080 캔버스
- PNG 다운로드
- 모든 편집은 사용자의 브라우저에서 처리

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일 전체를 저장소 루트에 업로드합니다.
3. GitHub 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source → Deploy from a branch**를 선택합니다.
5. `main` 브랜치 / `/ (root)`를 선택하고 저장합니다.
6. 잠시 후 GitHub Pages 주소가 생성됩니다.

별도의 Node.js 빌드나 서버가 필요하지 않습니다.

## 기술 구조

- HTML / CSS / JavaScript
- Fabric.js 5.3.1 CDN
- 캐릭터와 기본 그래픽은 SVG
- 사용자 업로드 이미지는 브라우저 메모리에서 Data URL로 처리

## 개인정보/업로드 파일

사용자가 올린 이미지는 이 앱 자체의 서버로 전송하지 않습니다. PNG 저장도 브라우저에서 직접 수행합니다. 단, Fabric.js는 CDN에서 로드되므로 인터넷 연결이 필요합니다.

## 확장 아이디어

- 밈 템플릿 JSON 저장/불러오기
- 1080×1920 세로형 SNS 모드
- GIF/움짤 생성
- SVG 요소 내부 색상 편집
- 텍스트 폰트/외곽선/그림자/정렬 도구
- 실행 취소/다시 실행
- 모바일 터치 제스처 최적화
